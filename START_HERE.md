## 🎮 Quick Actions

### Add a Menu Item
1. Open `src/data/foods.js`
2. Add a new item to the array
3. Save - page refreshes automatically

### Change Colors
1. Open `src/styles/index.css`
2. Change CSS variables
3. Save - updates instantly

### Change Restaurant Name
Search for "Warung Nusantara" in:
- `src/components/Navbar.jsx`
- `src/components/Hero.jsx`
- `src/components/Footer.jsx`

### Deploy to Internet
```bash
npm run build
# Upload dist/ folder to Netlify, Vercel, or GitHub Pages
```
